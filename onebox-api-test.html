Authentication

Exchange your client credentials for a Bearer token. The token is valid for 12 hours (43 200 s) and must be included in all subsequent requests.

POST https://api.oneboxtds.net/oauth/token

Headers
Content-Type application/x-www-form-urlencoded
Body (form-encoded)
grant_type    = client_credentials
channel_id    = 2287
client_id     = seller-channel-client

Get Sessions

Returns the paginated list of sessions (matches) available on this channel. The live channel currently has 21 sessions. Each session includes event info, venue, date window, price range, and per-zone availability.

Authorization Bearer <access_token>
Query params (optional)
limit 100 (default)
